  • Agent Narrow the Bash(python3 scripts/*) and Bash(bash scripts/*) allow rules; git diff*/log* allow rules permit --output writes; .factory/HANDOFF.md is tracked and injected into agent context without provenance.
  • Supply chain factory.json pins the external skills to the mutable 'main' (security-audit-run's 'pinned ref' claim is wrong); install-codegraph.sh installs unpinned npm and curl|sh.

What is already solid

  • Strict CSP (script-src 'self', frame-ancestors 'none', form-action 'none'); challenges are served as text/plain
  • No DOM sinks: copy.js uses static data-copy values and textContent; no inline scripts (enforced by check_page.py)
  • The Worker reflects no request data; there are no CORS headers, cookies or redirects
  • No pull_request_target; production deploys run only on push to main behind the production environment, using the lockfile
  • Dashboard output is HTML-escaped; no secrets are tracked; .env* and .dev.vars are ignored and denied
